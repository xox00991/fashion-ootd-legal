Privacy Policy — fashion ootd

Last updated: 19 November 2026

fashion ootd is a private tool used only by its owner with the owner's own TikTok accounts.

Data used

When an account is connected through TikTok Login, the tool receives an access token and basic account information (such as the account's open ID and display name) from TikTok. These are used only to upload the owner's videos as drafts to that same account.

Storage

Tokens are stored only on the owner's own computers. They are not sold, shared or sent to anyone other than TikTok.

Other people's data

The tool does not collect, store or process data about any other TikTok users.

Removing access

Access can be removed at any time in the TikTok app under Settings and privacy → Security → Manage app permissions, which also stops the tool working for that account.

Contact

Questions: open an issue on this site's GitHub page.
